# Leçons apprises

## 1. L'ordre des ACL est critique
Une mauvaise position d’une règle peut casser tout le réseau.

## 2. ACL ≠ Firewall
Les ACL sont stateless → nécessité de gérer explicitement les flux retour.

## 3. NAT et ACL interagissent fortement
L’ordre des opérations influence les résultats.

## 4. Gateway doit toujours être accessible
Sinon aucun trafic ne peut sortir.

## 5. La micro-segmentation est essentielle
Réduction de la surface d’attaque.
