# Vue d'ensemble du projet

Ce projet simule une infrastructure réseau d’entreprise avec une approche orientée cybersécurité.

L’objectif est de reproduire des problématiques réelles :
- segmentation réseau
- contrôle des flux
- exposition contrôlée
- isolation des zones sensibles

Une attention particulière a été portée à :
- la cohérence des politiques
- la validation des règles
- la traçabilité des flux
